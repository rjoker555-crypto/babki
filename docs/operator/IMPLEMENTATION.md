# Главный агент VoltMaster: матрица контроля

Обновлено 07.10.2026. Заменяет отчёт первого этапа. Результаты и границы проверки: [контрольный отчёт](CONTROL_REPORT_2026-10-07.md). [Каталог](tool-catalog.json) содержит 60 предметных инструментов. Старый универсальный CRUD закрыт для новых записей и не засчитывается как покрытие.

Д — активный директор с закрытым допуском; Ф — финансист; Б — бухгалтер; У — управляющий; П — прораб назначенного/ответственного объекта. Производственные права: Д/Ф/Б/У и П только своей области. Подачи дополнительно проверяют существующие полномочия исполнителя. «План» — конкретное подтверждение с владельцем, версией и повторной проверкой свежего оригинала. Чтение проходит под JWT/RLS.

Общие команды подключены к локальному ручному интерфейсу и развёрнутому агенту. Новый frontend пока не опубликован по указанию владельца. Не все 60 инструментов отдельно проверены реальной моделью.
